# Křížovkář 3.0 – novinová (švédská) křížovka

Tahle verze je udělaná ve stylu novinové / švédské křížovky:
- nápovědy jsou přímo v mřížce,
- slova se doplňují vodorovně i svisle,
- modrá políčka tvoří tajenku,
- průběh hry se automaticky ukládá.

## Soubory
- `index.html`
- `style.css`
- `script.js`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

## Nahrání na GitHub Pages
1. Rozbal ZIP.
2. Nahraj všechny soubory do repozitáře.
3. Zapni GitHub Pages z větve `main`.

## Poznámka
Tato verze je už vzhledově přepracovaná do novinového stylu. Pokud budeš chtít, další krok může být:
- více křížovek,
- větší databáze nápověd,
- generování nové švédské křížovky tlačítkem,
- zvětšená políčka nebo ještě „papírovější“ vzhled.
